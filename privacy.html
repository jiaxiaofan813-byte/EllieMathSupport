Privacy Policy

Effective and last updated: October 30, 2026

This policy describes EllieMath's current offline-first iPhone and iPad app, its public help website, and optional support through the EllieMathSupport GitHub repository. The developer responsible for these EllieMath services can be contacted through the official support repository, maintained by GitHub account jiaxiaofan813-byte.

At a glance: The current app does not send children's practice records to the developer. Learning records stay on the device. The app has no advertising, third-party analytics or cross-app tracking. The message board is unavailable.

1. Information stored on your device

EllieMath stores the information needed to provide and personalize practice: the selected learner age band and visual theme; chosen subjects and difficulty settings; questions, answers, mistakes and hints; practice dates, times and personal bests; unfinished sessions, progress, difficulty changes, stickers, points, check-ins, and parent-created reward descriptions and redemption records. Age bands are learning-space choices, not dates of birth.

Parent access uses a four-digit PIN. A salted verification hash, rather than the PIN in plain text, is stored locally. The PIN is a parent-access control; it does not encrypt all learning records. Anyone with access to an unlocked device may still have access to device data.

This information is used on the device to run practice, adapt difficulty, restore progress, calculate rewards and show parent reports. It is not uploaded to an EllieMath account or developer-operated server. Children do not need to register, provide a real name, or enter an email address to use the current app.

2. Advertising, analytics and device access

The current app contains no advertising or third-party analytics SDKs, and does not track users across apps or websites. We do not sell or rent children's learning records. The app does not request access to the camera, microphone, contacts, photos or precise location. Spoken counting and multiplication facts use system speech playback, not microphone recording.

Apple may independently process App Store transactions, downloads, device backups or diagnostic information under your Apple settings and Apple's policies. This policy does not replace Apple's privacy policy.

3. Children and the message board

EllieMath is designed for children with parent or guardian involvement. The current app does not provide public posting or messaging: the board is labeled Coming Soon and cannot be used to send messages. There is no active online board service in this release. If an online feature is introduced, its data practices and any necessary parent controls or permissions will be explained before it becomes available.

Support is intended for parents and guardians. Please do not submit a child's name, photo, school, parent PIN or other private information in public feedback. Parent-provided reward text also does not need personal information.

4. Retention, deletion and your choices

Parents can review records in Parent report and Practice history, change learning settings, switch local learner spaces and edit or remove parent-created rewards. Detailed answer records are pruned to a rolling 90-day window during app use. Other progress and summary records may remain until the app's local data is removed, subject to the app's storage limits.

To remove the current device's app data, delete EllieMath using iOS or iPadOS settings. Offloading the app keeps its documents and data and is not the same as deleting it. Existing device or iCloud backups may retain an earlier copy depending on your Apple settings; manage those backups separately. Restoring a backup can restore app data. EllieMath does not provide its own cloud synchronization, server-side account, or remote recovery of local progress or a forgotten PIN.

5. Website visits and voluntary support

Our public website is hosted on GitHub Pages. We have not added analytics scripts, advertising, cookies or tracking pixels to these pages. GitHub may process connection and usage information, such as an IP address and browser details, when you visit its services. See GitHub's privacy statement.

If you choose to submit a GitHub Issue, your GitHub username, the report and any attachments are visible to the developer and the public. We use the information you choose to provide to respond to feedback, diagnose problems and improve EllieMath. A GitHub account is needed to post; visiting this policy does not require one. Public reports may remain available as support history until removed and may have been copied by others.

You can edit or delete your own GitHub content where GitHub allows it. For a removal request to the EllieMath maintainer, use the support repository and provide only the affected issue URL, without repeating private information. For GitHub-held data or sensitive content that needs private handling, use GitHub Support and the privacy contacts in GitHub's policy. We cannot remove third-party copies or data held solely by GitHub.

6. Questions and updates

For privacy questions, a parent or guardian can contact the EllieMath maintainer through GitHub Issues. This is a public channel: do not include sensitive details. We will update this page and its date when these practices change. Material changes involving new online features will also be explained in the app before those features are made available.

隐私政策

生效及最后更新日期：2026 年 10 月 30 日

本政策适用于当前以离线使用为主的 EllieMath iPhone / iPad App、公开帮助网站，以及通过 EllieMathSupport GitHub 仓库提供的自愿反馈服务。EllieMath 开发者通过 GitHub 账号 jiaxiaofan813-byte 维护官方支持仓库，您可由此联系我们。

简要说明：当前 App 不会把孩子的练习记录上传给开发者。学习数据保存在设备上，没有广告、第三方统计或跨 App 追踪，留言板尚未开放。

1. 保存在设备上的信息

为提供练习和个性化设置，App 会在设备上保存：所选年龄段学习空间和主题、题型及难度、题目与作答、错题及提示、练习日期和用时、个人最佳表现、未完成练习、学习进度及难度变化、贴纸、积分、签到，以及家长设置的奖励说明和兑换记录。年龄段是学习空间选项，并不是出生日期。

家长区域使用四位 PIN。设备上保存的是加盐校验哈希，不是明文 PIN。PIN 用于限制家长区域入口，并不代表所有学习记录都经过加密；能够使用已解锁设备的人仍可能接触设备数据。

这些信息在本机用于运行练习、调整难度、恢复进度、计算奖励和生成报告，不会上传至 EllieMath 账号或开发者服务器。孩子无需注册，也无需填写真实姓名或邮箱。

2. 广告、统计和设备权限

当前 App 不含广告或第三方统计 SDK，不进行跨 App 或网站追踪。我们不出售或出租孩子的学习记录。App 不请求使用相机、麦克风、通讯录、照片或精确位置。数字和乘法的朗读使用系统语音播放，不录制声音。

Apple 可能依据您的 Apple 设置及其政策，独立处理商店交易、下载、设备备份或诊断信息，相关处理参见 Apple 隐私政策。

3. 儿童使用与留言板

EllieMath 面向儿童，并由家长或监护人参与管理。当前留言板标注为 Coming Soon，不能发布或发送信息，本版本没有启用在线留言服务。未来如增加在线功能，我们会在开放前说明其数据处理方式，以及必要的家长控制或授权。

支持服务面向家长或监护人。请勿在公开反馈中提交孩子姓名、照片、学校、家长 PIN 或其他隐私信息；自定义奖励说明也不需要包含个人信息。

4. 保留、删除与选择

家长可以在报告和练习历史中查看记录，调整学习设置、切换本地学习空间，以及编辑或删除自定义奖励。详细作答记录会在使用 App 时按滚动 90 天窗口清理；其他进度或总结记录可能在 App 存储限制内继续保留，直至本地数据被移除。

要删除当前设备上的 App 数据，请通过 iOS / iPadOS 设置删除 EllieMath。“卸载 App”会保留文稿和数据，与“删除 App”不同。设备或 iCloud 备份可能根据您的 Apple 设置保留旧副本，需另行管理；恢复备份可能恢复 App 数据。EllieMath 没有自建云同步或服务器账号，开发者无法远程恢复本地进度或遗忘的 PIN。

5. 网站与自愿反馈

公开网站托管于 GitHub Pages。我们未在页面加入统计脚本、广告、Cookie 或追踪像素。GitHub 在提供服务时可能处理 IP 地址、浏览器信息等连接或使用数据，详见 GitHub 隐私声明。

如果您主动提交 GitHub Issue，您的 GitHub 用户名、反馈内容和附件会被开发者及公众看到。我们使用您主动提供的内容来回复反馈、排查问题和改进 App。提交反馈需要 GitHub 账号；阅读本政策不需要。公开反馈可能作为支持历史持续保留，直至被移除，也可能被他人复制。

您可以使用 GitHub 提供的功能编辑或删除自己的内容。向 EllieMath 维护者请求移除内容时，请仅提供相关 Issue 链接，不要重复发布隐私信息。GitHub 持有的数据或需要私下处理的敏感内容，可通过 GitHub Support 或其隐私声明中的联系方式处理。我们无法删除第三方副本或仅由 GitHub 持有的数据。

6. 联系与更新

有关隐私的问题，请由家长或监护人通过 GitHub Issues 联系 EllieMath 维护者。这是公开渠道，请勿附带敏感信息。当数据处理方式发生变化时，我们会更新本政策和日期；涉及新在线功能的重要变化，也会在功能开放前于 App 中说明。
